# 🍅 CASERO

**CASERO** es una aplicación móvil y web desarrollada con Ionic y Angular, orientada a facilitar la **visualización, ubicación y gestión de ferias libres y sus puestos** en un mapa interactivo. Permite a usuarios explorar ferias cercanas y a administradores gestionar su información de forma simple, visual y accesible.

> 💡 *Nuestro objetivo es digitalizar la experiencia de recorrer una feria libre, acercando a feriantes y vecinos mediante una solución moderna, intuitiva y de impacto social.*

---

## 🚀 Funcionalidades principales

- 🔍 **Mapa interactivo:** Ubica ferias con precisión usando Leaflet + OpenStreetMap.
- 📋 **Detalle de ferias:** Consulta ubicación, días y horarios de funcionamiento.
- 🧺 **Gestión de ferias:** Crea, edita y elimina ferias (solo para administradores).
- 🛒 **Gestión de puestos:** Vincula puestos a ferias, define su nombre, foto y productos.
- 🧑‍💼 **Perfil de usuario:** Visualiza y actualiza tu información y avatar.
- 🔐 **Autenticación segura:** Inicio de sesión con email + magic link vía Supabase.
- ⚠️ **Validaciones y alertas:** Mensajes amigables en formularios y acciones críticas.
- 🌞 **Modo claro forzado:** Diseño visual moderno, limpio y minimalista.
- 📱 **Responsive Design:** Optimizado para móviles, tablets y escritorio.

---

## 🛠️ Tecnologías utilizadas

- **Angular + Ionic** – Framework frontend híbrido para móviles y web.
- **Supabase** – Backend-as-a-Service (auth, base de datos y storage).
- **Leaflet** – Librería de mapas interactivos.
- **OpenStreetMap** – Fuente abierta de datos cartográficos.
- **SCSS** – Estilos personalizados adaptables a la marca.
